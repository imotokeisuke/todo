# 台帳 — タスク管理アプリ

アイテム（管理したいトピック）ごとに TO（やること）と DO（完了したこと）を記録できる、個人用のシンプルなタスク管理アプリです。iPhone のホーム画面に追加して、ネイティブアプリのように使うことを想定しています。

- データはお使いのブラウザ内（localStorage）に保存されます。
- Firebase を設定すると、**ログイン不要の「同期コード」**で複数の端末のデータを同期できます（設定は任意。設定しない場合は今まで通り端末内保存のみで動作します）。
- 1人で使うことを想定した個人用アプリです。

## ファイル構成

```
index.html          … アプリ本体（これがトップページになります）
manifest.json       … ホーム画面追加時のアプリ名・アイコン設定
firebase-config.js  … 他端末との同期設定（任意。使わない場合は編集不要）
icon-180.png        … iPhoneホーム画面用アイコン
icon-192.png        … PWA用アイコン（小）
icon-512.png        … PWA用アイコン（大）
```

## GitHub にアップロードして公開する手順（ブラウザだけでOK）

コマンド操作は不要です。GitHub のWeb画面だけで完結します。

1. [github.com](https://github.com) にログインする（アカウントがなければ無料登録）。
2. 右上の「+」→「New repository」をクリック。
3. Repository name に好きな名前（例: `my-ledger-app`）を入力し、Public を選択して「Create repository」をクリック。
4. 作成されたリポジトリ画面で「uploading an existing file」（または「Add file」→「Upload files」）をクリック。
5. このフォルダの中身（`index.html`、`manifest.json`、`firebase-config.js`、`icon-180.png`、`icon-192.png`、`icon-512.png`）を**すべて**ドラッグ＆ドロップする。
6. 下部の「Commit changes」をクリックしてアップロードを確定する。
7. リポジトリ画面上部の「Settings」タブを開く。
8. 左メニューの「Pages」をクリック。
9. 「Build and deployment」の「Branch」を `main`（またはデフォルトブランチ）、フォルダを `/ (root)` に設定し、「Save」をクリック。
10. 数十秒〜数分待つと、ページ上部に公開URLが表示されます（例: `https://ユーザー名.github.io/my-ledger-app/`）。このURLがあなたのアプリのアドレスです。

## iPhoneでアプリとして使う手順

1. 上記で発行された公開URLを iPhone の **Safari** で開く（Safariで開くことが重要です）。
2. 画面下部の共有ボタン（□に↑）をタップ。
3. 「ホーム画面に追加」をタップし、名前を確認して「追加」をタップ。
4. ホーム画面にアイコンが追加され、以降はアイコンをタップするだけでアプリのように起動します（アドレスバーなどが表示されないフルスクリーン表示になります）。

## 複数端末で同期する（Firebase設定・任意）

設定しなくてもアプリは通常通り使えます。iPhoneとiPad、iPhoneとPCなど、複数の端末で同じデータを見たい場合のみ設定してください。**ログインやアカウント作成は不要**で、「同期コード」という10桁のコードを他の端末に入力するだけで繋がります（日記アプリなどでよくある方式です）。**無料の範囲（Sparkプラン）で十分に使えます。**

### 1. Firebaseプロジェクトを作成する（**"Create a project"**）

1. [Firebase console](https://console.firebase.google.com/) を開き、Googleアカウントでログインする。
2. **「プロジェクトを作成」**(**"Create a project" / "Add project"**)をクリックする（名前は自由。Googleアナリティクスは無効でよい）。

### 2. Firestore（データベース）を有効にする

1. 左メニュー「構築」(**"Build"**) →「Firestore Database」→「データベースの作成」(**"Create database"**)をクリック。
2. ロケーションを選び（例：`asia-northeast1 (Tokyo)`）、**「本番環境モードで開始」**(**"Start in production mode"**)を選択する。

### 3. Authentication（匿名認証）を有効にする

ログイン画面は作りませんが、Firestoreにデータを安全に保存するため、**Anonymous（匿名）認証**という「ユーザーには見えない」認証だけを有効にします。

1. 左メニュー「構築」(**"Build"**) →「Authentication」→「始める」(**"Get started"**)をクリック。
2. 「Sign-in method」タブで**「匿名」**(**"Anonymous"**)を選び、**有効にして保存**する。
   - メール/パスワードなど他の方法は有効にしなくてOKです。

### 4. Webアプリを登録し、設定値を取得する

1. 左上の歯車アイコン→「プロジェクトの設定」(**"Project settings"**)→「全般」(**"General"**)タブを一番下までスクロール。
2. 「マイアプリ」(**"Your apps"**)で `</>`（**ウェブ**）のアイコンをクリックしてアプリを登録する。
3. **「Firebase Hosting も設定します」のチェックは入れず**、名前を入力して「アプリを登録」(**"Register app"**)。
4. 次の画面で **`<script>` タグ**を使う方を選ぶ（**npm ではありません**）。表示されたコードの中の `firebaseConfig = { ... }` の値だけを使います。コードそのものをコピーする必要はなく、そのまま「コンソールに進む」(**"Continue to console"**) で閉じてOKです。

```js
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "my-todo-app-xxxxx.firebaseapp.com",
  projectId: "my-todo-app-xxxxx",
  storageBucket: "my-todo-app-xxxxx.appspot.com",
  messagingSenderId: "123456789012",
  appId: "1:123456789012:web:xxxxxxxxxxxxxxxxxxxxxx"
};
```

### 5. `firebase-config.js` を編集する

お手元の `firebase-config.js` をテキストエディタで開き、末尾の `window.FIREBASE_CONFIG = {...}` の中身を、手順4の値に置き換えて保存してください。

### 6. Firestoreのセキュリティルールを設定する（重要）

Firebaseコンソールの「Firestore Database」→「ルール」(**"Rules"**)タブを開き、内容を以下に置き換えて**「公開」**(**"Publish"**)をクリックしてください。

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /syncData/{code} {
      allow read, write: if request.auth != null;
    }
  }
}
```

このルールは「匿名認証さえ済んでいれば読み書きできる」という設定です。ログイン機能は無い代わりに、**同期コード自体が実質的なパスワードの役割を果たします**。同期コードは他人に教えないようにしてください（コードを知っている人は誰でもそのデータを見られる仕組みのため）。

### 7. GitHubに再アップロードする

`index.html` と `firebase-config.js` を、前述の手順でGitHubリポジトリに上書きアップロードしてください。

### 8. アプリで同期を設定する

1. 公開URLを開き、画面右上の**☁️アイコン**をタップする。
2. **今データが入っている端末**では「この端末のデータで同期を始める」をタップ。10桁の同期コードが発行され、今のデータがそのままクラウドにアップロードされます（データは消えません）。
3. 発行されたコードをメモ・スクリーンショットなどで控えておく。
4. **2台目以降の端末**では、同じく☁️アイコンを開き、「他の端末で発行したコードをお持ちの場合」の欄にそのコードを入力して「このコードで接続する」をタップ。クラウド上のデータがその端末に反映されます。
5. 以降は、いずれかの端末でTOを追加・完了・削除すると、他の端末にも自動的に（リアルタイムで）反映されます。
6. 同期をやめたい場合は、☁️アイコン→「この端末の同期を解除」で解除できます（データはその端末にそのまま残ります）。

## まとめて削除機能

- 「進捗管理」タブのTO一覧、および「アイテム」タブのアイテム一覧に「まとめて削除」ボタンがあります。
- タップするとチェックボックス形式になるので、削除したいものを選び「削除する」を押してください。
- 「全て選択」「選択解除」でまとめて操作することもできます。

## 更新したいとき

修正したファイルをGitHubのリポジトリ画面で該当ファイルを開き、鉛筆アイコン（Edit）から編集するか、再度「Upload files」で同じファイル名を上書きアップロードしてください。「Commit changes」をすると、公開URLの内容も自動的に更新されます（反映まで1分程度かかることがあります）。

## プライバシーについて

このリポジトリを Public（公開）で作成した場合、コード自体は誰でも閲覧可能になりますが、アプリ内に入力したタスクやメモなどのデータそのものは公開されません。

- Firebaseを設定しない場合：データは各利用者のブラウザ内（localStorage）にのみ保存され、他人に見られることはありません。
- Firebaseを設定した場合：データはあなたのFirebaseプロジェクトのFirestoreに保存されます。ログイン機能が無い代わりに、**同期コードが分からない限り他人はデータにアクセスできません**（同期コードは推測されにくいランダムな10桁です）。念のため、同期コードはパスワードと同じように第三者に教えないようにしてください。`firebase-config.js` に含まれる `apiKey` 等の値はFirebaseの仕組み上公開されても問題ない情報ですが、心配な場合はリポジトリを Private に設定することもできます（その場合は GitHub Pages の公開に有料プラン（GitHub Pro等）が必要になる点にご注意ください）。
